# Next.js deployment security update — 2026-10-08

The deployment rejected Next.js 15.3.3 for CVE-2025-66478. Next.js and eslint-config-next are pinned to 15.5.27, the current published 15.x maintenance patch. React and React DOM are pinned together to 19.0.8. The npm lockfile was regenerated by npm.

References:
- https://nextjs.org/blog/CVE-2025-66478
- https://nextjs.org/blog/september-2026-security-release

Validation: all 29 API-contract/failure-path tests and 17 buyer-auth validation tests pass. Production build passed on Next.js 15.5.27, including type checking and static export of all 64 current working-tree routes.

This fixes the reported vulnerable Next.js release. It is not a clean audit of every supporting dependency: npm audit reports 18 remaining entries (4 moderate, 14 high), including transitive CSS/image/build-tool packages. Some suggested remedies are major upgrades or have no available patched dependency chain. No forced audit downgrade or unrelated major migration was applied. The detailed local audit is preserved under .figma-reference/security/.

Dependencies were installed with lifecycle scripts disabled; the sharp and unrs-resolver install-script approval notices are separate from the Next.js version rejection. Do not blanket-approve lifecycle scripts to resolve the version error. Deployment must use this commit and its lockfile, then rerun the build. A successful local build does not confirm a remote deployment.
